- **로컬 Action 정본 = eval 216 킷 실측** (홀드아웃 Action은 참고용 — 추출기가 train 도메인에선 처음 보는(OOD) 것처럼 헤맴, [08](08_로컬리더보드_구축.md)/[12](12_팀원리포트_반영.md) §2).
- 서버 기준점(앵커): 베이스라인 0.5167(DINO+Video 0.9502) / 정적 0.302949(DINO+Video 0.4364). 제출 전 이 기준점으로 서버 점수 어림.
- 제출은 공식 킷으로만 CSV 생성, 나중에 손보는 후처리 금지. 제출 전 submissions.csv에서 **오늘 팀 남은 횟수(하루 3회) 확인**.
- Public 순위에 과하게 맞추지 말 것 — 최종 선택은 로컬의 처음 보는 셋(unseen) 최고점 (Public 30%는 노이즈).
- **E4 성공 기준: 로컬·서버 모두 0.303 미만** (정적 정체선 = 정지 영상 점수 한계).

## 4. 시간 예산 (규칙 5 — 학습·추론 모두 RTX PRO 6000 96GB 1대 기준)
- 추론 한도 **샘플당 16.7초**. 실험 설계 시 항상 이 예산으로 환산 (T4 실측 18.87초 = 이미 초과 → 스텝 감축 필수).
- best-of-N(여러 번 만들어 최선 고르기)은 N배 시간 — 예산 안으로 제약.
- 학습 4일: 최종 레시피(전처리→학습→추론)가 GPU 1대로 4일 안에 재현돼야 함. 탐색용 병렬 실험은 자유.

## 5. Git·코드
- 비공개 저장소 https://github.com/qgasdg/INChall26 main 한 줄기(trunk-based), 큰 구조 변경만 합치기 요청(PR).
- 실험 커밋은 `exp-NN:` 접두. 서버↔로컬 코드 이동은 git으로만 (직접 복사(scp) 금지).
- 서버 환경 = `bash scripts/setup_server.sh` 한 줄 (uv.lock이 정본, 킷 requirements를 따로 pip 설치 금지 — omegaconf 버그 반영됨).
- 저장 모델(ckpt)·대용량 산출물은 repo 금지 → HF 비공개 저장소 경유. **산출물은 세션 끝나기 전 회수가 최우선** (팀원 산출물 2번 잃은 교훈, [external/inha_progress_summary.md](external/inha_progress_summary.md) §6).

## 6. 인프라 역할 (07 §1.1 갱신)
| 자원 | 역할 |
|---|---|
| Kaggle T4 (무료) | 짧은 재현·검증 (팀원 레시피 확립됨) |

## 8. 협업 프로토콜 (2026-07-18 추가 — 두 클로드 충돌 방지)
- **교환 지점 = repo 단일화.** 팀원·팀원의 클로드도 산출물을 repo에 직접 커밋 (파일 전달 금지). 양쪽 클로드는 **세션 시작 시 이 룰북 + [BOARD.md](BOARD.md) 필독**을 각자 지침(CLAUDE.md 등)에 명시.
- **소통 채널 = 슬랙 (InChall26 워크스페이스)** *(7/18 추가, T 승인 대기)*. 비동기 논의·알림·핑은 슬랙으로, 단 결정·산출물의 정본은 여전히 repo(§7 — 슬랙 합의도 repo에 기록돼야 확정). **작업 시작 전 슬랙 확인 + 작업 중 간간이 확인** — 클로드 세션도 세션 시작 필독(룰북+BOARD)에 슬랙 확인을 포함.
- **영역 소유권** — 남의 영역은 직접 수정하지 않고 BOARD에 이슈로 제기:

| 영역 | 소유 |
|---|---|
| `local_eval/`, `scripts/`, 인프라(setup·uv.lock), 룰북·문서 정합 | Y (우리) |
| Kaggle 노트북, 학교 A100·W2 학습 코드(`src/`), T측 실험 리포트 | T (팀원) |
| `results/` CSV 2종, `docs/LOG.md`, `docs/BOARD.md` | 공용 — **append-only(추가 전용: 남의 줄은 고치지 말고 새 줄만 덧붙임)** |

- **착수 선언 = 슬랙** *(7/19 개정 — BOARD 선언에서 전환, T 승인 대기)*: 모든 작업은 **슬랙 채널에 착수 메시지를 올린 뒤 시작** (담당·작업명·예상 시간). 클로드 세션도 예외 없음 — 같은 실험 동시 실행 사고를 구조적으로 차단. [BOARD.md](BOARD.md)는 대기(백로그)·완료(결과 링크) 기록용으로 유지, "진행 중" 섹션은 폐지.
- **클로드 산출물 규격**: 결론 먼저 · 실측/추정 구분 · config는 실효값 검증 여부 명시(§7 η 규칙) · 파일명은 docs/ 번호 체계 계승.
- **일일 리듬**: 각자 LOG 한 줄 + 슬랙 근황 공유(BOARD는 대기·완료만 정리) + 리더보드 스냅샷. **룰북 개정만 상호 승인 필수**, 나머지는 선기록 후공유.
