## 3. 점수·제출
- **로컬 Action 정본 = eval 216 킷 실측** (홀드아웃 Action은 참고용 — extractor가 train 도메인 OOD, [08](08_로컬리더보드_구축.md)/[12](12_팀원리포트_반영.md) §2).

- **E4 성공 기준: 로컬·서버 모두 0.303 미만** (정적 정체선).

## 4. 시간 예산 (규칙 5 — 학습·추론 모두 RTX PRO 6000 96GB 1대 기준)
- 추론 한도 **16.7초/샘플**. 실험 설계 시 항상 이 예산으로 환산 (T4 실측 18.87s = 이미 초과 → 스텝 감축 필수).
- best-of-N은 N배 시간 — 예산 내로 제약.
- 학습 4일: 최종 레시피(전처리→학습→추론)가 단일 GPU 4일 안에 재현돼야 함. 병렬 탐색은 자유.

## 5. Git·코드
- Private repo https://github.com/qgasdg/INChall26 main 단일(trunk-based), 큰 구조 변경만 PR.
- 실험 커밋은 `exp-NN:` 접두. 서버↔로컬 코드 이동은 git으로만 (scp 금지).
- 서버 환경 = `bash scripts/setup_server.sh` 한 줄 (uv.lock 정본, 킷 requirements를 따로 pip install 금지 — omegaconf 버그 반영됨).
- ckpt·대용량 산출물은 repo 금지 → HF private repo 허브 경유. **산출물은 세션 종료 전 회수가 최우선** (팀원 산출물 손실 2회 교훈, [external/inha_progress_summary.md](external/inha_progress_summary.md) §6).

## 6. 인프라 역할 (07 §1.1 갱신)
| 자원 | 역할 |
|---|---|
| Kaggle T4 (무료) | 짧은 재현·검증 (팀원 레시피 확립됨) |
