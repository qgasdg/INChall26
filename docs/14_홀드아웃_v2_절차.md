# 홀드아웃 v2 병합 절차 (2026-07-18, Y 기안 · T 승인 — 확정)

> 소유: `local_eval/` = Y. §5의 룰북 §2 개정은 **상호 승인 필수**(룰북 [§8](13_팀_룰북.md)) → **2026-07-18 T 승인으로 확정**, 룰북 §2에 반영됨.
> 선행 조건 **충족**: T가 488 목록을 [local_eval/holdout_t488.json](../local_eval/holdout_t488.json)으로 커밋 완료.

## 결론 먼저
- **488 실측 정정**: 앞선 추정 "in-domain 400 + unseen 88"은 **오류**. 실제 = **indomain 328(328ep/120ds) + unseen 160(80ep×2clip/8ds)** ([holdout_t488.json](../local_eval/holdout_t488.json) meta).
- **설계 원칙**: T의 in-domain 328은 **그대로 보존**(서버 앵커 0.5167/0.302949 ↔ 로컬 D+V 매핑이 이 위에 서 있음). **unseen 티어만** "데이터셋 통째" 방식으로 교체·보강한다.
- **핵심 긴장**: eval 사촌 데이터셋은 홀드아웃 최적 후보인 **동시에** 최고의 학습 데이터다. 특히 `Loki0929/so100_duck`은 T의 커리큘럼 상위(187 에피소드)라 통째로 빼면 학습 손실이 크다 → duck은 **학습에 남기고** 사촌 대표는 다른 둘로.

## 절차 (5단계)

### 1. T의 488 목록 입수 (선행 — ✅ 완료)
- [local_eval/holdout_t488.json](../local_eval/holdout_t488.json) 커밋 완료 (impl 레지스트리 holdout_v1, seed 42 유래). 각 sample = {tier, dataset(user/dataset), episode_index, start, length, sample_id}.
- **현 unseen 8개 데이터셋**: AndrejOrsula/lerobot_double_ball_stacking_random, CSCSXX/pick_place_cube_1.18, Gano007/so100_medic, LemonadeDai/so100_coca, ZGGZZG/so100_drop0, **aractingi/push_cube_offline_data(=셋업A 사촌, v2 유지)**, jpata/so100_pick_place_tangerine, therarelab/so100_pick_place_2.

### 2. unseen 데이터셋 선정 (충돌 해소 포함)
사촌형 힌트는 [10_조사_eval도메인.md](10_조사_eval도메인.md) §사촌. T의 기존 절충(push_cube는 실험 중 분리, E-final에서 복귀)을 확장:

| 티어 | 데이터셋 | 근거 |
|---|---|---|
| unseen-사촌 | `aractingi/push_cube_offline_data` (셋업A 사촌) | 검은 매트형 top-down (sim ~0.72–0.77) |
| unseen-사촌 | `frk2/so100large` (셋업B 사촌) | 나무 책상형 측면 뷰 |
| unseen-일반 | 비사촌 소형 1~2개 | 순수 일반화 측정용 (사촌 편향 배제) |

- **`Loki0929/so100_duck`(셋업B 사촌)은 홀드아웃에 넣지 않고 학습에 남긴다** — 187 에피소드 학습 가치 우선. 사촌 대표는 위 둘로 충분.
- **T의 현 unseen 8개와의 정합**: `aractingi/push_cube_offline_data`는 이미 T unseen에 있음 → v2 **유지**. `frk2/so100large`는 T unseen에 **없음 → 신규 추가**. 나머지 6개(double_ball/pick_place_cube/so100_medic/so100_coca/so100_drop0/pick_place_tangerine/pick_place_2 중)는 비사촌 일반 티어 후보로 1~2개 잔류, 나머지는 학습 복귀 검토.
- **채점 비용 관리**: 티어당 **80~120 에피소드로 서브샘플**(seed 고정). 새 에피소드라 채점을 매번 다 돌리면 비싸다(§4).

### 3. 구현 (Y, `local_eval/` 소유)
- `make_holdout.py` 확장 → `holdout_v2.json` 생성·커밋.
- 현 스크립트는 `N_UNSEEN_DATASETS=7` 무작위 선정([make_holdout.py](../local_eval/make_holdout.py) L22/L47-51) → **명시 지정 목록 + 서브샘플**로 교체. in-domain은 T의 328을 [holdout_t488.json](../local_eval/holdout_t488.json)에서 그대로 로드(재추첨 금지).
- 결정론: seed 0 유지, 분할 목록·시드 repo에 고정.

### 4. 재앵커
- v2의 unseen 티어에서 **정적·베이스라인 기준행을 재측정**해 원장([local_lb.csv](../results/local_lb.csv))에 기록.
- 비용: 정적 생성은 공짜, **베이스라인 생성은 T4로 ~2시간** (새 에피소드라 T의 기존 488 생성물 재활용 불가).

### 5. 룰북 §2 개정 (✅ 2026-07-18 T 승인 — 룰북 §2 반영 완료)
- **학습 제외 규칙 명문화**: v2 unseen 데이터셋(push_cube_offline_data, so100large, 비사촌 일반 티어)은 **모든 실험의 학습에서 제외**, **E-final(최종 재학습)에서만 복귀**.
- **수치 정합**: v2 확정 이후 원장의 홀드아웃 수치는 **v2만 사용** (이전 홀드아웃 수치와 혼용 금지).
