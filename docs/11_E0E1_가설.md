# 4090 세션(E0~E1) 검증 가설

> ⚠️ **판정 완료 (당일)**: 팀원 리포트 합류로 H1·H2·H5 확정, **H3 전제 붕괴(베이스라인은 이미 결정론 — 코드 추적 확정)**, H4 부분 답변. 판정 근거와 세션 목적 재정의는 [12_팀원리포트_반영.md](12_팀원리포트_반영.md) — 이 문서는 기록용으로 보존.

> 작성 2026-07-18. 첫 GPU 세션의 목적은 점수가 아니라 **이후 실험을 신뢰할 수 있게 만드는 가설 검증**. 절차는 [09_E0_런북.md](09_E0_런북.md), 전략 배경은 [04_파이프라인.md](04_파이프라인.md)·[07_운영전략.md](07_운영전략.md).

## H1. 캘리브레이션 — "베이스라인 무수정 제출 = Public 0.517"
- 근거: 리더보드 35위 이하 다수가 0.51708 수렴 (LOG 7/18 스냅샷). 역산: Action 0.579×0.4=0.232 → DINO+Video 평균 cos dist ≈ 0.48
- 확인 방법: E0 제출 1회 (팀 구성 전 제출 요건 겸함)
- 맞으면: 로컬 파이프라인=서버 채점 정렬 증명 → 이후 실험은 로컬 리더보드로 돌리고 확신 있을 때만 제출 (3회/일 예산 절약)
- 어긋나면: **킷 체인 재현 어딘가 버그 — 원인 규명이 다른 모든 것에 우선**

## H2. Action 재현 — "우리가 만든 제출 CSV의 Action ≈ 0.579"
- 서버에서 베이스라인을 직접 돌려 만든 CSV의 Action 실측(로컬 계산됨)이 sample_submission 평균 0.579 수준이어야 함
- 제출 전 확인 가능. 크게 다르면 프레임 정렬/인코딩 문제 → 제출 보류하고 규명

## H3. cheap win — "무학습 추론 튜닝만으로 0.517을 깬다" (E1)
- 베이스라인 확인된 허점: η=1.0(확률적 샘플링)·배치 1
- 가설: **η=0 결정론화만으로 DINO/Video 개선** (확률 노이즈에 의한 프레임 흔들림 제거) + 스텝 수 스윕으로 품질-시간 곡선 확보
- CFG는 봉인 확정 ([06_조사_action_cfg.md](06_조사_action_cfg.md) — 학습된 uncond 경로 부재)
- 맞으면: 학습 없이 0.517 무리 이탈 = 첫 개선 신호

## H4. 시간 예산 — "추론 1h 안에 best-of-N 여지가 있다"
- 216샘플 추론 벽시계 실측 + 배치 병렬 압축률 확인
- 예: 1회 15분이면 N=3~4 생성 → Action 실측(로컬 공짜)으로 최선 선택하는 E8 전략의 예산 성립 여부 결정
- 4090 실측은 RTX PRO 6000 기준으로 보수적 환산 기록 (규칙 5: 추론 1h도 PRO 6000 기준)

## H5. (보너스, 제출 예산 보고 결정) 정지영상 앵커 — "첫 프레임 반복이 생각보다 강한 베이스라인"
- 근거: train 홀드아웃에서 정지영상 DINO 0.033/Video 0.039 ([08_로컬리더보드_구축.md](08_로컬리더보드_구축.md)) vs 베이스라인 역산 0.48 → 베이스라인 생성 품질이 정지영상보다 크게 나쁠 가능성
- 정지영상의 eval Action은 로컬 실측 가능 → DINO/Video만 제출 1회로 확인하면 총점 지배 구조를 실증
- E0 결과 확인 후 제출 여부 결정 (예산 소모와 교환)

## 성공 기준
H1·H2 = 신뢰 기반 구축, H3·H4 = 첫 점수 개선 + E8 설계 근거, H5 = 평가식 구조 실증.
다섯 개가 정리되면 E3+ 학습(96GB 서버, 고비용 구간)을 "로컬 개선이 서버 점수로 이어진다"는 확신 위에서 시작한다.
