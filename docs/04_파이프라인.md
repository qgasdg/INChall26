# 전체 파이프라인 v1 → v1.3 (노션 요약)

> 출처: 팀 노션 [1차 전체 파이프라인 v1](https://app.notion.com/p/1-v1-Video-Generation-39f6af58538080c68b5bd59085fdda3b) (v1: 07-16, v1.1 자기검증, v1.2 킷 코드 분석 반영, exp03 사이트+baseline 분석 / 2026-07-18 수집)
> 노션에 첨부 PDF 있음: inha-pipeline-v1-3.pdf (1.6MiB)

## 목표·제약
Score = 0.3×DINO(cos) + 0.3×Video(cos) + 0.4×Action(MAE) 최소화.
학습 ≤4일 · 추론 ≤1h (RTX PRO 6000 96GB 1장), 외부 데이터·eval 학습 금지, 킷 변경 금지, 3회/일 제출.

## 문제 정식화
POMDP 관점: 학습 대상 = `p(o_{t+1:t+16} | o_t, a_{t:t+15})`. action[t]≈state[t+1]이므로 팔 포즈는 action이 결정 → 실질 과제는 "액션→픽셀 렌더링 + 물체 반응".

## 8단계 구조
S0 킷 해부·로컬 리더보드 → S1 데이터 → S2 아키텍처 → S3 학습P1 → S4 학습P2(Action 특화) → S5 추론 → S6 실험 운영·제출 → S7 재현성·코드 제출

## v1.2 핵심 확정 사항 (submission_kit 전수 분석 = exp02)
- ★ **Action Component는 킷이 로컬에서 최종 MAE 스칼라를 계산해 CSV에 기록** → 제출 전 216샘플 전수(Private 포함) **정확히 계산 가능**. best-of-N도 Action은 실측 기반. DINO/Video는 GT feature가 서버에만 → train 홀드아웃 프록시.
- 확정 규격: mp4 **정확히 16프레임**(fps 무관) · 공통 전처리 = **320×512 zero-pad letterbox** · DINO = timm `vit_small_patch14_dinov2.lvd142m` 518×518 (16,384) · Video = R3D-18 (16,112,112) 비등방 squish (512,) · Action = 320×512 [-1,1] 입력.
- Action extractor 구조: **Conv3D(temporal stride 없음) → Bi-GRU(256) → (16,6)**. 자체 surrogate IDM은 동일 클래스 재학습으로 전이 갭 최소화.
- **생성 해상도는 320×512 native 기본** (킷이 어차피 320×512 변환 — 왕복 손실 제거), 640×480과 ablation.
- 킷 전처리 체인(letterbox→518/112/extractor)은 전부 interpolate/pad → **미분가능 복제 가능** (E6 직접 파인튜닝 손실용).
- 스케일 참고: sample_submission Action mean 0.579 (0.088~1.148) vs cosine 통상 0.0x~0.5 → **Action이 가중치+스케일 양면에서 총점 지배 가능성**.

## v1.1 기법 자기검증
| 기법 | 판정 |
|---|---|
| frame-level adaLN 액션 주입 | 유지 (concat/cross-attn ablation) — 16액션↔16프레임 1:1 + IRASim 근거 |
| REPA | Track A(스크래치) 한정 — 파인튜닝엔 근거 약함 |
| VideoREPA | 후순위 ablation (교사 VideoMAEv2 ≠ 채점기 R3D-18) |
| GRPO | 예비로 강등 — 로컬 보상 전부 미분가능 → **주력 = DRaFT식 직접 역전파** (DRaFT·AlignProp) |
| 자체 IDM cycle·결정론 추론·로컬 리더보드·2단 홀드아웃 | 유지 |

## 파인튜닝 판단 (확정)
**주력 = Wan2.2-TI2V-5B (Apache-2.0) LoRA(r=64~128) + frame-level adaLN 액션 모듈(zero-init)**
근거: ① DINO 0.3은 미공개 장면 외관 prior 요구 ② 4일 = 5B LoRA 충분, 스크래치 부족 ③ Apache-2.0 + 네이티브 TI2V ④ Wan2.2-VAE(4×16×16) latent 소형.
대안 서열: Wan2.1-1.3B > CogVideoX-2B > LTX/SVD(라이선스 애매) > Cosmos(리스크). Track A(베이스라인 200~400M 확장) = 헤지·실험 플랫폼.
사전학습 백본 규정 리스크 해소: **주최 스스로 DynamiCrafter_512 HF 백본을 다운로드해 사용** → 선례 확보.

## 실험 사다리 E0~E8
| 실험 | 내용 | 신호 |
|---|---|---|
| E0 | 베이스라인 재현 + 로컬 리더보드 + 제출 1회 | 기준점 + 로컬-서버 캘리브레이션 + GT self-test로 프레임 정렬 확정. **팀 구성 전 1회 제출 요건도 겸함** |
| E1 | 무학습 추론 튜닝 (η=0 결정론화, CFG 스윕, 스텝, 배치 병렬) | cheap win — 베이스라인 추론이 η=1.0(확률적)·CFG 미사용·배치1이라 개선 여지 확정 |
| E2 | Wan2.2 zero-shot I2V (액션 무시) | prior의 DINO/Video 상한 |
| E3 | + LoRA 도메인 적응 (액션 없음) | 도메인 갭 축소 폭 |
| E4 | + frame-level adaLN (concat·cross-attn ablation) | **Action 급락 기대 — 최대 개선 지점** |
| E5 | + latent IDM cycle loss | Action 추가 개선 |
| E6 | + 전체 산식 직접 FT (DRaFT-k, 킷 전처리 미분가능 복제) | 3성분 동시 개선 |
| E7 | (조건부) GRPO — E6 OOM/불안정 시에만 | |
| E8 | 추론 최적화·best-of-N (Action 실측 + DINO/Video 프록시) | 1h 내 점수-시간 파레토 → 최종 후보 |

## S1~S7 요약
- **S1**: 윈도우 `[t..t+15]↔[t..t+15]` 동일 인덱스(조건 포함 16프레임 출력, exp03 확정). so100 z-score. sqrt 균형 샘플러. **수평 flip 금지(액션-기하 불일치)·hue 금지**, 약한 밝기/대비만. stride 4 → ~25만 윈도우.
- **S2**: Wan2.2-TI2V-5B LoRA + adaLN(zero-init) 주력, Track A 헤지, 텍스트 조건 제거.
- **S3** (~2일): L_FM 도메인 적응. ckpt 선택 = 로컬 리더보드 점수 (train loss 아님).
- **S4** (~1.5일): 자체 IDM(킷 동일 클래스, 픽셀+latent) → latent cycle loss `‖IDM_lat(ẑ₀)−a‖₁` → 전체 산식 직접 FT(DRaFT-k + EMA/KL 앵커). GRPO 예비.
- **S5**: 결정론(η=0), 320×512 native 16프레임, h264 저압축(CRF 낮게), best-of-N(Action 실측), CSV는 킷으로만.
- **S6**: expNN 로그·단일 변수 ablation·제출 절약·최종 파일 = **로컬 unseen-val 최고** 수동 선택.
- **S7**: 상대경로·UTF-8·환경 명세(torch 2.7.1, lightning 1.9.3, timm — 킷 requirements 정합)·라이선스 매니페스트·4일/1h 재현 스크립트 (8/21 14:00 마감).

## exp03 — 대회 사이트 + baseline 코드 전수 분석
### 조건 프레임 확정 (3중 근거)
**제출 영상 = [조건 프레임(t=0) 포함 16프레임] = 실질 미래 15프레임.**
① 학습: `LeRobotSO100Dataset.__getitem__` — frames[t..t+15] ↔ actions[t..t+15] 동일 인덱스 ② 추론: DDIM 인페인팅(mask=cond_mask)으로 frame 0 고정 ③ 킷 `build_inference_batch` — buffer[0]=조건 이미지.
→ frame 0은 "공짜 정답" — 우리 모델도 출력 0번에 조건 프레임 포함해야 GT와 정렬.

### 베이스라인 실체
- DynamiCrafter LatentVisualDiffusion, **UNet 11M** (model_channels 32), temporal conv+attn, T=16.
- 백본: HF `Doubiiu/DynamiCrafter_512` — VAE/CLIP만 리로드, **UNet은 스크래치**.
- v-prediction + zero-SNR rescale, perframe_ae, in_channels 8 (latent4+조건latent4 concat) + CLIP 이미지 cross-attn + action_conditioned(6dim), 텍스트는 빈 캡션.
- 해상도 320×512 (latent 40×64), 학습 batch1×accum2, lr 1e-4, 100K steps/48h, val 5% (seed 0).
- **추론: ddim 50스텝, CFG=1.0(미사용), η=1.0(확률적!), batch 1, seed 0** → E1 개선 여지 확정.
- 카메라 auto = wrist/gripper/arm 제외. eval config에 `camera_key: observation.images.top` 잔재 → **eval GT가 top-view 계열 힌트**.
- baseline의 metrics.py(MSE/PSNR/SSIM/LPIPS/FVD/FID)는 리더보드 산식과 무관 — 로컬 리더보드는 exp02 스펙으로 자체 구축.
