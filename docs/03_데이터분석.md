# 데이터 분석 리포트 v2 (노션 요약)

> 출처: 팀 노션 [데이터 분석](https://app.notion.com/p/39f6af58538080ec9b58ea0377c81bbc) (작성 2026-07-16 / 2026-07-18 수집)

## 1. 결론 요약
- **태스크**: 현재 프레임 1장(640×480 PNG) + 미래 16스텝 행동(16×6 npy) → **16프레임(6fps) 영상 생성**. 평가 샘플 **216개** (Public 30% / Private 70%).
  - ※ exp03에서 확정: 출력 16프레임은 **조건 프레임(t=0) 포함**, 실질 미래 15프레임 ([04_파이프라인.md](04_파이프라인.md) 참고).
- **train은 100% 공개 데이터**: HF LeRobot **SO-100 커뮤니티 데이터셋 128개**를 6fps로 다운샘플. 최소 101개(79%)가 SmolVLA(2506.01844) 사전학습 목록과 겹침. 단 **외부 데이터 금지 → 원본 HF(30fps·멀티뷰) 추가 사용 불가**. 허용 라이선스 공개 가중치 사전학습 모델은 사용 가능.
- **action[t] ≈ state[t+1]** (평균 오차 1.65°, corr 0.99+): action은 리더암 목표각 → 팔 포즈는 action이 거의 결정. 모델의 실질 과제 = "액션→픽셀 렌더링 + 물체 반응".
- eval 이미지 스팟체크 4장은 train 장면과 불일치 → **미공개 장면 포함 추정** → 장면 암기보다 action-일반화 필요.

## 2. 데이터 구성
```
open (1)/
├── data/
│   ├── train/                      # 128개 LeRobot 데이터셋 (<user>/<dataset>)
│   │   ├── .../data/chunk-000/episode_XXXXXX.parquet
│   │   ├── .../meta/info.json, episodes.jsonl
│   │   ├── .../videos/chunk-000/<camera_key>/episode_XXXXXX.mp4
│   │   └── so100_action_statistics.json   # action 정규화 mean/std
│   └── eval/
│       ├── images/sample_000000~000215.png   # 시작 프레임 640×480
│       └── actions/sample_000000~000215.npy  # (16,6) float32, deg
├── baseline/        # DynamiCrafter 기반 action-conditioned latent video diffusion (11M UNet)
└── submission_kit/  # mp4 → feature CSV (평가 추출기 포함, 변경 금지)
```

## 3. Feature 상세 (parquet 행 = 프레임)
| feature | 형식 | 의미 |
|---|---|---|
| action | float32 (6,) | 리더암 목표 관절각[deg]: shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper |
| observation.state | float32 (6,) | 팔로워암 실측 관절각 |
| observation.images.image | 480×640×3 | h264 mp4 프레임 |
| timestamp | float32 | 1/6s 간격 |

- episodes.jsonl: 에피소드별 자연어 태스크 (pick-and-place 위주, 일부 부실).
- so100_action_statistics.json: count ≈ 전체의 95% (val 5% 제외 통계 추정). **eval action은 비정규화 deg → 이 통계로 z-score 필요**.

## 4. Feature 간 관계 (30개 데이터셋 표본, 4,408프레임)
- **action ↔ state**: corr 0.993~0.999 (gripper 0.939). `|a[t]−s[t+1]|=1.65° < |a[t]−s[t]|=2.25°` → action[t]은 사실상 state[t+1] 예측치.
- 관절 커플링: shoulder_lift↔elbow_flex +0.89 (실효 자유도 <6). shoulder_pan 독립.
- **gripper 특수성**: 파지 시 목표각-실측각 괴리 → action-state 잔차가 파지 이벤트 신호. Action MAE에서 gripper 차원 별도 모니터링 가치.
- 차원별 std 14~62 스케일 격차 → 정규화 필수. wrist_roll은 데이터셋 간 이질성 큼.

## 5. 평가 산식의 실체 (submission_kit 결합)
| 성분 | 가중치 | feature | 거리 |
|---|---|---|---|
| DINO | 0.3 | **DINOv2 ViT-S/14** CLS, 프레임별 16×384 | GT와 cosine distance |
| Video | 0.3 | **R3D-18**(Kinetics) 512-d 클립 feature | GT와 cosine distance |
| Action | 0.4 | 고정 action extractor 역추정 action | GT(정규화)와 MAE |

핵심 통찰:
- **분포 거리(FVD)가 아니라 per-sample feature 매칭** → "그럴듯한 영상"이 아니라 "그 장면 GT와 유사한 영상". 다양성은 리스크(고정 시드, 결정론 샘플링, guidance 튜닝).
- Action 0.4 + extractor 고정 → **extractor가 인식하기 좋게 팔 움직임을 선명히 렌더링**하는 것이 점수 40% 좌우.
- eval GT 영상은 서버에만 → **train 홀드아웃으로 로컬 리더보드 재현** 필수.
- Public ~65샘플로 노이즈 큼 + 3회/일 → Public 과적합 금지, 로컬 지표 신뢰.

## 6. 규정 제약 (전략 직결)
- 외부 데이터 금지 (HF 원본 30fps·멀티뷰 활용 불가), eval 학습 활용 금지 (pseudo-labeling 포함).
- 사전학습 모델: 공개 가중치 + 허용 라이선스 (MIT/Apache 2.0/CC BY/CC BY-NC 등).
- 컴퓨트: 학습 ≤4일, 추론 ≤1h (RTX PRO 6000 96GB 1장) → 216샘플 × 16프레임 = **샘플당 평균 ~16.6초**.
- 제출킷 변경 금지, CSV 후처리 금지.

## 7. 전략 우선순위
1. [최우선] Action fidelity (0.4): 조건 주입 방식 비교 + 로컬 자가 채점 루프.
2. [평가 재현] train 홀드아웃 로컬 리더보드 (0.3/0.3/0.4 그대로).
3. [샘플별 매칭] 결정론적·저분산 생성 세팅 튜닝.
4. [도메인 갭] 데이터셋 균형 샘플링, 색/조명 증강 (외부 데이터 없이).
5. [품질 필터링] SmolVLA식 큐레이션으로 저품질 데이터셋 제외 실험.
6. [컴퓨트 예산] 스텝 수·해상도 트레이드오프 사전 계산.

## 8. 한계
- 상관 분석은 30/128 데이터셋 첫 에피소드 표본. eval-train 대조는 8개 스팟체크. SmolVLA 겹침 101/128은 하한.
- 서버측 cosine 집계 방식(프레임 평균 vs flatten) 미공개 → 로컬에서 두 방식 병산.
