# 후속 조사 ① — action-CFG 가능 여부 (baseline 코드 정독, 2026-07-18)

> **한 줄 배경.** CFG(Classifier-Free Guidance)는 "조건(행동)을 얼마나 세게 따를지" 조절하는 손잡이다. "조건 있는 예측"과 "조건 없는(uncond) 예측"을 대비시켜 작동하는데, 이 조사는 지금 베이스라인에서 그게 되는지를 코드로 확인한 것이다.

> 근거 코드: `openaimodel3d.py` (action 임베딩·dropout), `ddpm3d.py:1294 prepare_batch_for_inference` (uncond 구성), `ddim.py:258` (CFG 분기), `ldwma/datasets/lerobot_so100.py` (caption 처리)

## 결론
**베이스라인 저장 모델(체크포인트)에는 학습된 "조건 없음(uncond)" 경로가 하나도 없다 (행동뿐 아니라 텍스트·이미지도).** CFG를 1보다 키우는 건 "학습된 적 없는 예측과 대비"하는 꼴이라 근거가 없다. 제대로 된 행동 CFG는 `action_dropout_prob>0`(학습 중 행동을 가끔 빼기)으로 (파인)튜닝해야 열린다 — **설정 한 줄이면 되고 구조를 바꿀 필요는 없다**.

## 상세 근거
1. **구조는 CFG 준비됨**: UNet에 `null_action_emb`("행동 없음"을 나타내는 학습 가능한 표현) 자리가 이미 있고, 행동이 없으면(act=None) 이걸 쓴다. 즉 행동 CFG용 설계 자체는 돼 있음.
2. **그러나 학습이 안 됨**: `null_action_emb`는 0에서 시작하는데, `action_dropout_prob=0`이라 학습 중 한 번도 안 뽑힘 → 학습 신호(기울기) 0 → **지금도 0인 채 방치** (모델이 "행동 없음"을 본 적 없음).
3. **텍스트 uncond도 무의미**: 학습 데이터의 캡션이 늘 빈 문자열("")이라, 5% 확률로 캡션을 ""로 바꾸는 처리는 **""을 ""로 바꾸는, 아무 효과 없는 동작(no-op)**이었음.
4. **추론 시 uncond 구성** (`prepare_batch_for_inference`): 조건 없음 = [빈 텍스트 표현 + **검은 이미지** 표현 + 조건프레임 압축표현(유지) + 행동 키 없음→null emb]. 검은 이미지도 학습된 적 없음 → 조건 없음 예측은 이중으로 처음 보는(OOD) 상태.
5. CFG 분기(`ddim.py`)는 세기=1.0이면 조건 없음 예측 자체를 건너뜀 — 현 베이스라인 설정에선 만들어지되 안 쓰임.

## E1/E4 설계 반영
- **E1(학습 없음)**: 행동 CFG는 봉인. 개선 수단은 η=0 결정론화·스텝 수·배치 병렬로 한정. (CFG를 살짝 훑어보는 건 비용이 싸니 로컬 점수로 한번 확인만 — 기대는 낮음.)
- **베이스라인 트랙에서 CFG를 원하면**: 기존 저장 모델에서 `action_dropout_prob≈0.1`로 이어서 파인튜닝 → null_action_emb가 학습되며 CFG 열림. 비용은 GPU 시간뿐, E1 결과가 좋을 때만 투자.
- **주력(Wan2.2) 트랙**: 행동 모듈을 새로 다는 것이므로 **처음부터 행동 dropout(~0.1)을 넣고 학습** — 추가 비용 없이 CFG 옵션 확보. 파이프라인 S2 설계에 반영할 것.
