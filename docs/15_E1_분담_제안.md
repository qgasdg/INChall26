# E1 분담 제안 (2026-07-18, Y → T 합의 대기)

> 룰북 [§8](13_팀_룰북.md) 영역 소유권상 E1은 T 로드맵과 중복 위험 → BOARD 이슈로 제기, 합의 후 착수. 아래는 Y 제안.

## 결론 먼저
- **E1은 Y가 인수, 제출 없음.** T는 크리티컬 패스(A100 확보 + W2/Wan2.2 구현)에 집중.
- η 발견([12](12_팀원리포트_반영.md) §3, 실효 η=0 확정) 이후 E1의 실체가 바뀌었다 — 남은 손잡이는 **ddim_steps(50→30/20/12), guidance_rescale(0.7 스윕), 배치 병렬**뿐.

## E1 목적 재정의 (점수 아님)
베이스라인은 E1을 아무리 튜닝해도 정적(0.3028)을 못 이긴다 — D+V 0.95 vs 0.44 갭은 스텝 수로 안 닫힘. 따라서 E1의 목적은:
1. **스텝-품질-시간 곡선 방법론 확보** — Wan2.2의 E8 추론 최적화 리허설.
2. **시간 예산 실데이터** — 16.7초/샘플 한도([룰북 §4](13_팀_룰북.md)) 대비 실측. (T4 실측 18.87s = 이미 초과 → 감축 곡선 필요.)
3. **홀드아웃 v2 채점 루프 첫 가동** ([14](14_홀드아웃_v2_절차.md)) — 제출은 안 함.

## 분담 근거
- T 크리티컬 패스 = A100 확보 + W2(Wan2.2) 구현. E1에 손 대면 크리티컬 패스가 느려짐.
- Y는 이번에 자체 Kaggle 레시피(마운트 경로 함정까지 해결)와 분석 루프를 확보 → E1 실행에 최적.
- **비용 확인**: config당 T4 생성 ~70분 + 킷 채점 5.6분 → 4개 config ≈ **5시간**, 주간 쿼터 30시간 내 여유.
