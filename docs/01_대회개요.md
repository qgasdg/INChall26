# 2026 인하 인공지능 챌린지 — 대회 개요

> 출처: [대회 페이지](https://dacon.io/competitions/official/236736/overview/description) (2026-07-18 조사)

## 대회명
**로봇 미래 행동 영상 생성: 월드 모델 챌린지**

## 과제 정의
- 입력: **현재 로봇 이미지 1장**(640×480 PNG) + **행동 시퀀스**(16×6 npy, deg)
- 출력: **조건 프레임(t=0) 포함 16프레임(6fps) 영상(mp4)** = 실질 미래 15프레임 생성 (exp03 코드 분석으로 확정, [04_파이프라인.md](04_파이프라인.md))
- 즉, 월드 모델(world model) 기반 조건부 비디오 생성 과제. 평가 샘플 216개.

## 평가 방식
```
Score = 0.3 × DINO Component + 0.3 × Video Feature Component + 0.4 × Action Component
```
- **낮을수록 좋음 (0에 가까울수록 좋은 점수)**
- DINO Component: 생성 영상 프레임별 시각 특징 vs 정답 — **코사인 거리**
- Video Feature Component: 시공간(비디오) 특징 유사도 — **코사인 거리**
- Action Component: 생성 영상이 행동 조건을 반영하는 정도 — **MAE 기반** (가중치 최대 0.4 → 가장 중요)
- 리더보드: Public 30% / Private 70% (사전 샘플링), 최종 시상은 Private 기준
- 상위 7팀은 재현 가능한 소스코드 제출 필수

## 핵심 규칙 (요약)
- 1일 최대 제출 3회
- 제출: `submission_kit/make_submission_csv.py`로 CSV 생성, 영상 파일명 `sample_000000.mp4` 형식
- 외부 데이터 사용 불가 (대회 제공 데이터만), 평가 데이터를 학습에 사용 금지
- 사전학습 모델: **공개 가중치 + 허용 라이선스(MIT, Apache 2.0, CC BY 등)만 가능**
- API 전용 모델(OpenAI, Gemini 등) 사용 불가
- 학습 시간 제한: **4일 (RTX PRO 6000 기준)** / 추론 시간: **1시간 이내**
- 언어: Python만
- Private 채점은 참가자가 선택한 1개 제출물 기준 (미선택 시 Public 최고점 자동 선택)
