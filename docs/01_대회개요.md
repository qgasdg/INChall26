# 2026 인하 인공지능 챌린지 — 대회 개요

> 출처: [대회 페이지](https://dacon.io/competitions/official/236736/overview/description) (2026-07-18 조사)

## 대회명
**로봇 미래 행동 영상 생성: 월드 모델 챌린지**

## 과제 정의
- 입력: **현재 로봇 사진 1장**(640×480 PNG) + **행동 시퀀스**(앞으로 할 동작을 시간순으로 적은 숫자표, 16스텝×6관절, 단위는 도(deg)의 npy 파일)
- 출력: **조건 프레임(t=0, 받은 시작 사진) 포함 16프레임(초당 6장, 6fps) 영상(mp4)** = 첫 장은 받은 사진 그대로이므로 실제로 새로 지어내는 미래는 15프레임 (exp03 코드 분석으로 확정, [04_파이프라인.md](04_파이프라인.md))
- 즉, **월드 모델**(로봇이 어떤 행동을 하면 화면이 어떻게 바뀔지 예측해 영상으로 그려내는 AI) 기반의 조건부 비디오 생성 과제(주어진 조건=시작 사진+행동에 맞는 영상 만들기). 평가 샘플 216개.

## 평가 방식
```
Score = 0.3 × DINO Component + 0.3 × Video Feature Component + 0.4 × Action Component
```
- **낮을수록 좋음 (세 항목 모두 정답과의 "거리"라, 0에 가까울수록 좋은 점수)**
- DINO Component(30%): 만든 영상의 각 장면이 정답 장면과 겉보기에 얼마나 닮았나 — **코사인 거리**(방향만 비교, 밝기·화질 차이는 무시)
- Video Feature Component(30%): 영상의 움직임 흐름이 정답과 얼마나 닮았나 — **코사인 거리**
- Action Component(40%): 영상 속 팔 움직임이 명령을 얼마나 잘 따랐나 — **MAE 기반**(평균절대오차, 예측과 정답이 평균 얼마나 어긋났나. 가중치 최대 0.4 → 가장 중요)
- 리더보드: Public 30% / Private 70% (사전 샘플링), 최종 시상은 Private 기준
- 상위 7팀은 재현 가능한 소스코드 제출 필수

## 핵심 규칙 (요약)
- 1일 최대 제출 **10회**
- 제출: `submission_kit/make_submission_csv.py`로 CSV 생성, 영상 파일명 `sample_000000.mp4` 형식
- 외부 데이터 사용 불가 (대회 제공 데이터만), 평가 데이터를 학습에 사용 금지
- 사전학습 모델(미리 학습돼 공개된 모델): **공개 가중치 + 허용 라이선스(자유 사용 허가된 것: MIT, Apache 2.0, CC BY 등)만 가능**
- API 전용 모델(외부 서버로 불러 쓰는 상용 모델: OpenAI, Gemini 등) 사용 불가
- 학습·추론 시간 제한 (규칙 5 원문 기준): **둘 다 RTX PRO 6000 (VRAM=GPU 메모리 96GB) 1대 기준** — 학습 최대 4일, 추론(만든 모델로 216문제 영상 뽑기)은 전체 1시간 이내
- 언어: Python만
- Private 채점은 참가자가 선택한 1개 제출물 기준 (미선택 시 Public 최고점 자동 선택)
