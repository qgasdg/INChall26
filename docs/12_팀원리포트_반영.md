## 3. ★불일치 해소 — 베이스라인의 η (우리 코드 추적으로 확정)

- 우리 04·LOG·11(H3)의 전제: "베이스라인은 η=1.0이라 매번 다르니(확률적), 결정론화하면 값싼 이득" — **폐기**.
- 팀원의 정정이 맞음을 코드로 직접 확인: 설정엔 `ddim_eta: 1.0`이라 적혀 있지만 → `generate_baseline_videos.py:104-118`에서 `**sample_kwargs`로 넘길 때 → `DDIMSampler.sample()`의 실제 인자는 `eta=0.0`(기본값)이 쓰이고, `ddim_eta`는 뒤쪽 `**kwargs`에 **조용히 삼켜져** 무시됨 → 결국 0.0이 전달. **베이스라인은 이미 결정론(매번 같은 결과)이었다.**
- 교훈(팀원 표현 채택): "설정값 ≠ 실효값 — 설정 파일 숫자를 믿지 말고 코드가 실제로 어떻게 쓰는지까지 따라가야 확정".
