# 리더보드 평가산식 분석 및 오류 최소화 전략 (노션 요약)

> 출처: 팀 노션 [리더보드 평가산식 분석](https://app.notion.com/p/39f6af585380808bbc66ea5031317d20) (작성 2026-07-16, 2차 갱신본 / 2026-07-18 수집)

## 1. 수식 정의
- **Cosine Distance(코사인 거리)** — DINO/Video 채점에 씀. 식은 `d_cos(u,v) = 1 − cosθ`, 값 범위는 [0,2]. 두 숫자 묶음이 가리키는 **방향만** 비교하고 **크기(밝기·대비·코덱 차이)는 무시**한다(스케일 불변 = 크기를 바꿔도 값이 안 변함). 그래서 밝기·화질·압축이 좀 달라도 벌점이 없다.
- **MAE(평균절대오차)** — Action 채점에 씀. 고정 IDM(영상만 보고 무슨 행동을 했는지 거꾸로 알아내는 채점 모델)이 우리 영상 `x̂`에서 되짚은 행동 `â = g(x̂)`을, 정답 행동 `a`와 한 칸씩 빼서 그 차이의 절댓값을 평균 낸 값 `(1/nT)Σ|â−a|`. 여기서 T=16(시간 스텝 16개), n=6(관절 6개).

## 2. 최소화 조건 (어떻게 하면 점수가 낮아지나)
- 코사인 거리는 우리 예측 `u`가 정답 `v`와 **같은 방향**일 때(`u = αv`, α>0) 최소가 된다. 즉 방향만 맞으면 되고 크기는 상관없다.
- 정답이 여러 개일 수 있는 상황(확률적)에서는, 코사인 손실을 가장 낮추는 답이 **정답들의 평균 방향**이다. 그래서 **여러 가지로 다양하게 만드는 것보다, 정답에 가깝게 한 방향으로 딱 찍는(결정론적) 예측이 유리**하다.
- MAE는 정답들의 **중앙값**(median, 줄 세웠을 때 한가운데)을 맞출 때 최소가 된다(MSE라면 평균). 이상치(튀는 값) 한두 개에 덜 흔들리고, 16개 시간 스텝에 벌점을 고르게 준다.
- MAE를 낮추는 길은 결국 "영상 속 팔이 명령대로 실제로 움직이고 → IDM이 그 행동을 되짚어 정답과 맞아떨어지는" 것이다. 이걸 **cycle consistency(순환 일관성: 행동→영상→다시 행동으로 돌렸을 때 원래대로 돌아옴)**라 부른다.

## 3. 왜 화면(feature)은 코사인, 행동(action)은 MAE로 재나
- DINO 같은 화면 특징은 **의미가 방향에 담겨** 있고, 크기를 무시해 코덱·후처리 변화에 강하며, 값이 [0,2]로 갇혀 있어 다른 항목과 더할 때 스케일이 잘 맞는다. → 코사인이 적합.
- 반대로 행동은 **크기 자체가 본질**이다. 2배 빠르게 움직이면 다른 행동인데, 코사인은 "방향이 같다"며 0점(완벽)으로 봐버려 부적합하다. MAE는 그런 문제도 없고 튀는 프레임에도 강하다.

## 4. 관련 논문 검증 (원문 대조 결과)
채점 세 항목(DINO·Video·Action)을 대회와 **똑같은 방식**(문제 하나하나마다 생성 영상 vs 정답을 코사인+MAE로 비교)으로 쓰는 논문은 **없다**. 대회 산식은 「EWMBench 계열(DINO+궤적) + FVD 계열(영상 특징) + IDM 기반 행동 평가」를 문제별로 단순화한 변형이다.
- EWMBench (2505.09694): 3요소 구조상 가장 유사하나 self-consistency/diversity/tracking 기반.
- WorldArena (2602.08971): DINO cosine(프레임 간), V-JEPA 유사도, NDTW 궤적.
- IRASim (2406.14540): "trajectory-to-video는 다양성보다 재구성" — 대회 철학과 일치.
- EVA (2603.17808): frozen IDM 보상 + KL 정규화 구조 참고(보상 함수는 다름).
- FVD (1812.01717): Video Feature Component의 원류.

## 5. 항목별 점수 낮추는 전략
### A. DINO (30%) — 프레임 하나하나의 겉모습·의미
- 채점 킷(submission_kit)이 쓰는 전처리를 우리 파이프라인에서도 **똑같이 재현**한다(채점과 학습이 어긋나지 않게). 색·외관을 억지로 바꾸는 데이터 증강은 최소화.
- 영상을 압축했다 푸는 방식(latent diffusion)이라면 **VAE(압축·복원 부품)의 복원 품질부터 점검**한다. VAE가 디테일을 뭉개면 DINO 점수가 아무리 잘해도 어느 밑선 밑으로 못 내려간다.
- **REPA**(논문 2410.06940): 생성 모델 내부 표현을 채점용 DINOv2 특징에 맞춰 정렬 — 학습하는 공간과 채점하는 공간을 일치시킨다.
- 로컬 DINO 점수로 여러 번 만들어 제일 좋은 걸 고르기(best-of-N).

### B. Video (30%) — 시간에 따른 움직임 흐름
- fps·프레임 수·클립 길이를 킷 추출기 규격과 정확히 맞춘다.
- 시간을 함께 보는 구조(temporal attention/3D)가 필수다. 프레임을 따로따로 만들면 어른거림(flicker)이 생겨 특징이 뒤틀린다.
- 움직임을 과하게 매끈하게 다듬지 말 것(temporal smoothing 과잉 금지) — 움직임의 세기 통계 자체가 특징에 반영되기 때문.

### C. Action (40%, 최대 가중치) — IDM이 되짚은 행동의 MAE
- 행동과 프레임의 시점을 정확히 맞춘다(한 칸 어긋나면 off-by-one으로 MAE가 바로 오른다). 움직임 많은 구간을 더 많이 학습(오버샘플링).
- **IRASim식 frame-level conditioning**: 프레임마다 그 시점의 행동을 주입하는 방식(adaLN/cross-attn, 논문에서 효과 검증됨).
- 학습 데이터로 **우리 자체 IDM을 학습**해, 순환 일관성 보조 손실 `‖IDM(x̂)−a‖₁`을 만든다 = 채점 함수를 미분 가능하게 흉내 낸 대리물(surrogate).
- EVA식 강화학습(RL) 구조를 빌려 쓸 땐 보상을 −MAE(IDM(x̂), a)로 바꾼다. KL 정규화(원본에서 너무 벗어나지 않게 잡는 안전장치)로 편법(reward hacking) 방지.
- 행동 조건 세기(CFG) 조절, 대리 IDM의 MAE 기준 best-of-N.

## 6. 항목 간 상충 관계 (트레이드오프)
- 세 항목은 우리 영상이 정답과 **완전히 똑같아지면(x̂ = x\*) 셋 다 동시에 0**이 된다 → 근본적으로 서로 싸우는 관계가 아니다. 상충은 모델 용량·불확실성·신호 배분에 한계가 있을 때만 생긴다(모두를 동시에 다 잘하긴 어려운 지점 = Pareto frontier).
- 정적 영상(첫 프레임을 그대로 유지): Action(40%)에서 점수 폭탄 — DINO 하나만 보고 최적화할 때 빠지는 함정.
- 행동을 너무 세게 밀기(높은 CFG)나 행동 RL 과잉: DINO·Video가 나빠진다 — 그래서 guidance(세기)는 세 지표를 동시에 재보고 골라야 한다.
- 정답에 가깝게 한 방향으로 찍는(결정론적) 생성: 세 지표에 모두 유리 — 상충 아님.

## 7. 핵심 포인트
1. **Action(40%) 최우선**: 프레임별 행동 주입 + 자체 IDM 대리물.
2. 하루 3회만 제출 가능 → **로컬 채점 파이프라인이 모든 튜닝의 전제**(제출 안 하고도 점수를 미리 재봐야 함).
3. 다양성은 억제하고, 정답을 결정론적으로 충실히 재현하는 걸 우선.
4. 최종 채점 파일 1개는 손으로 골라 낸다(Public 순위에만 과하게 맞춰지는 과적합 주의).
