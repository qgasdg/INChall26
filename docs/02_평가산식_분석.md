# 리더보드 평가산식 분석 및 오류 최소화 전략 (노션 요약)

> 출처: 팀 노션 [리더보드 평가산식 분석](https://app.notion.com/p/39f6af585380808bbc66ea5031317d20) (작성 2026-07-16, 2차 갱신본 / 2026-07-18 수집)

## 1. 수식 정의
- **Cosine Distance** (DINO / Video Feature): `d_cos(u,v) = 1 − cosθ`, 범위 [0,2]. **스케일 불변** — 방향만 비교, norm 무벌점 (밝기/대비/코덱 변동에 관대).
- **MAE** (Action): 고정 IDM `g`로 영상에서 역추정한 행동 `â = g(x̂)` vs 기준 행동 `a`의 `(1/nT)Σ|â−a|`. T=16 타임스텝, n=6 행동 차원.

## 2. 최소화 조건
- Cosine: 최소점 `u = αv (α>0)` — 방향 일치가 전부. 기울기는 u에 직교(회전만 시킴).
- 정답이 확률적일 때 기대 cosine 손실의 최소해 = 정규화된 정답 feature들의 **평균 방향** → **다양성보다 회귀적(결정론적) 예측이 유리**.
- MAE: 최소해는 median (MSE는 mean). 기울기 −sign(e)로 이상치 강건, 모든 타임스텝 고른 벌점.
- MAE 최소화 경로 = "영상 모션이 조건 행동을 물리적으로 구현 → IDM이 a 복원"하는 **cycle consistency**.

## 3. 왜 feature는 cosine, action은 MAE인가
- DINO 계열 표현은 의미가 방향에 실림, 스케일 불변으로 코덱/후처리 강건, [0,2] 유계로 가중합 스케일 정합.
- 행동(물리량)은 크기가 본질 — cosine은 "2배 빠른 동일 방향"을 0으로 판정해 부적합. MAE는 IDM 이상치 프레임에 강건.

## 4. 관련 논문 검증 (원문 대조 결과)
세 컴포넌트를 대회와 동일 형태(per-sample, 생성 vs 정답, cosine+MAE)로 쓰는 논문은 **없음**. 대회 산식은 「EWMBench류(DINO+궤적) + FVD류(video feature) + IDM 기반 행동 평가」의 per-sample 단순화 변형.
- EWMBench (2505.09694): 3요소 구조상 가장 유사하나 self-consistency/diversity/tracking 기반.
- WorldArena (2602.08971): DINO cosine(프레임 간), V-JEPA 유사도, NDTW 궤적.
- IRASim (2406.14540): "trajectory-to-video는 다양성보다 재구성" — 대회 철학과 일치.
- EVA (2603.17808): frozen IDM 보상 + KL 정규화 구조 참고(보상 함수는 다름).
- FVD (1812.01717): Video Feature Component의 원류.

## 5. 컴포넌트별 최소화 전략
### A. DINO (0.3) — 프레임 단위 외관·의미
- submission_kit 전처리를 로컬 파이프라인에서 재현(채점-학습 불일치 제거). 색상/외관 증강 최소화.
- latent diffusion이면 **VAE 재구성 품질 먼저 점검** (VAE가 디테일 뭉개면 DINO cosine 하한 발생).
- **REPA** (2410.06940): diffusion 내부 표현을 DINOv2 feature에 정렬 — 채점 공간과 학습 정렬 공간 일치.
- 로컬 DINO 점수 기반 best-of-N.

### B. Video Feature (0.3) — 시공간 동역학
- fps·프레임 수·클립 길이를 kit 추출기 규격과 정합.
- temporal attention/3D 구조 필수 (프레임별 독립 생성은 flicker → feature 왜곡).
- 과도한 temporal smoothing 금지 (모션 강도 통계 자체가 feature에 반영).

### C. Action (0.4, 최대 가중치) — IDM 복원 행동 MAE
- 행동-프레임 동기화 검증 (off-by-one이 MAE 직접 증가). action-rich 클립 오버샘플링.
- **IRASim frame-level conditioning** (프레임별 adaLN/cross-attn으로 해당 시점 행동 주입 — ablation 검증됨).
- train으로 **자체 IDM 학습** → cycle-consistency 보조 손실 `‖IDM(x̂)−a‖₁` = 채점 함수의 미분가능 surrogate.
- EVA식 RL 구조 차용 시 보상은 −MAE(IDM(x̂), a)로 교체. KL 정규화로 reward hacking 방지.
- 행동 조건 CFG 스케일 튜닝, surrogate IDM MAE 기반 best-of-N.

## 6. 트레이드오프
- 세 컴포넌트 모두 x̂ = x*(완전 재구성)에서 동시에 0 → **본질적으로 적대적이지 않음**. 상충은 용량/불확실성/신호 배분 제약의 Pareto frontier에서 발생.
- 정적 영상(첫 프레임 유지): Action 0.4 폭탄 — DINO 단독 최적화의 함정.
- 높은 CFG/행동 RL 과잉: DINO/Video 악화 — guidance는 3지표 동시 실측으로 선택.
- 회귀적(결정론적) 생성: 3지표 공통 유리 — 상충 아님.

## 7. 핵심 포인트
1. **Action(0.4) 최우선**: frame-level conditioning + 자체 IDM surrogate.
2. 하루 3회 제출 → **로컬 채점 파이프라인이 모든 튜닝의 전제**.
3. 다양성 억제, 결정론적 고충실 재구성 우선.
4. 최종 채점 파일 1개 수동 선택 (Public 과적합 주의).
